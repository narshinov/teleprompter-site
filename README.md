# Teleprompter — сайт

Лендинг, политика приватности, условия использования и поддержка для iOS-приложения Teleprompter for Video Camera.
Статический сайт без сборки, публикуется через GitHub Pages из ветки `main`.

- `/privacy/` — Privacy Policy (ссылка для App Store Connect и экрана настроек)
- `/terms/` — Terms of Use
- `/support/` — FAQ и форма, которая открывает письмо в почтовом приложении.
  Поля можно предзаполнить: `support/?app=1.0&ios=18.1&device=iPhone17,1&topic=Bug%20report`

Локально: `python3 -m http.server 8765` и открыть http://localhost:8765/.
